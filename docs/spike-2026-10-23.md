# Spike, 2026-10-23 — driving Claude Desktop on Windows from a Linux agent

Target: Windows 11, standard user over RDP, Claude Desktop (Microsoft Store build 3.6556.2.0).
Driver: Cua Driver 0.34.1 (pinned; installer verified SHA256 and the Authenticode signature
„Cua AI, Inc."), daemon in the user's interactive session, reached as `ssh … cua-driver mcp --socket`.
All numbers below come from commands run that day; token figures are estimates (method stated).

## 1. Can it see inside the app?

| Driver | What the accessibility tree shows of Claude Desktop |
|---|---|
| CursorTouch Windows-MCP 0.8.8 | the window frame only: „Kis méret", „Teljes méret", „Bezárás" |
| Cua Driver 0.34.1 | the web content: 73–146 elements with labels (`Button "Add plugin"`, `TabItem "Plugins"`, `MenuItem "Add marketplace"`, `ComboBox "URL …"`) |

Clicking by element (UIA Invoke / Expand / Select) works in the background. Keystrokes into the Electron
window need `delivery_mode: foreground` (the driver says so in its error).

## 2. What one look at the screen costs

One screen (Settings → Plugins), estimated input tokens. Text ≈ characters / 3.5; image ≈ w·h / 750
after the 1568 px resize. No model was called (`spike/token_cost.py`).

| Representation | Tokens |
|---|---|
| accessibility tree, full markdown (8330 chars) | 2380 |
| accessibility tree, compact: labelled actionable elements only (59) | 707 |
| built-in Windows OCR lines with x,y (67 lines) | 419 |
| window screenshot 1202×797 | 1278 |
| full-screen screenshot 1920×1080 | 1844 |
| screen-changed hash | 0 |

The full tree costs **more** than a screenshot. The compact tree and OCR are the cheap rungs.
A `get_window_state` round trip over SSH: 0.5 s.

## 3. Built-in OCR (Windows.Media.Ocr), no install

Full screen 1920×1080: capture 109 ms, decode 61 ms, recognition **112 ms**, 67 lines with boxes.
Only `en-GB` is installed, yet „Mérési jel" came through with its accents.
Lines are cut where windows overlap (the sidebar under a modal). Script: `spike/ocr-windows.ps1`.

## 4. A tape, two modes

`tapes/claude-desktop-add-marketplace-dialog.yaml`: Customize → Plugins → Add plugin → Add marketplace →
Add from a repository → type a URL → Use → Cancel. Changes nothing.

| Mode | Steps | Time | Snapshots | Model calls |
|---|---|---|---|---|
| test | 25/25 | 8.5 s | 19 | 0 |
| video | 25/25 | 41.8 s | 16 | 0 |

Video: Cua `start_recording` (ffmpeg gdigrab, 1920×1080 H.264), captions burned with the Windows
host's ffmpeg 9.0.1 full build (`drawtext`, Segoe UI), plus an `.srt` beside it. 39.7 s, 0.9 MB.
Every tool call is in `runs/<stamp>/audit.jsonl`; only tools on the runner's allowlist can be called.

Authoring took four tries, each fixing one wrong assumption, which is exactly what an app map records:
the repository card's label carries its description (prefix match), the disabled Sync button is not in
the tree, the URL field is a ComboBox that opens an input and a „Use …" option, `Ctrl+,` does not open
Settings (the sidebar's Customize does), and Plugins there is a `TabItem`, not a `Button`.

## Windows pitfalls met (all reproducible)

1. **Redirection Guard (os error 448).** From an SSH session Windows refuses to traverse junctions the
   user created: `uv`'s Python and Cua's `bin` both sit behind one. Fix: run installers in the
   interactive session (a one-off `schtasks /it` task), and call binaries by their real directory.
2. **Credential Manager is unwritable from SSH** (`wincredman`): same fix, the interactive session.
3. **PowerShell 5.1 reads BOM-less scripts as ANSI**: a non-ASCII character breaks the parse silently
   (task exit 1, no output). Keep generated `.ps1` files ASCII.
4. **No HOME for the daemon**: `~` in a Cua path fails („the home directory is unavailable"); pass absolute paths.
5. **ffmpeg 9 dropped `-filter_script`**: use `-/filter:v <file>`.
6. **Env vars do not reach the per-call `mcp` process**: the first run printed an update notice, so the
   update check had run. The runner now sets `CUA_DRIVER_RS_UPDATE_CHECK=false`, telemetry off and
   `CUA_DRIVER_DISABLE_RUN_SCRIPT=1` on the ssh command line too.
7. **A minimised or disconnected RDP window** stops rendering; keep it open (or hold the session with a
   headless FreeRDP from Linux — not yet tried).

## What this says about the design

- The driver layer exists (Cua); do not rebuild it.
- The value is in the tape layer: selectors by role + label (with prefix), waits, `expect`, captions, a
  test mode and a video mode from one file, an allowlist and an audit log. A deterministic run costs no
  model tokens at all; the model is only needed to author or repair a tape.
- Per-app maps are worth it for flows that repeat: each authoring fix above is a fact about the app that
  the next tape should not have to rediscover.
