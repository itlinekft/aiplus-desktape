How it works

Look cheaply

A compact list of labelled actionable elements and open dialogs: about 860 tokens for a busy screen, about 120 for what changed after a click. OCR next, and an image only when nothing else will do.

Act one step, keep it

The agent clicks, types and checks one step at a time. A step that passed is appended to a YAML tape; one that failed is not.

Replay without a model

The runner never calls a model. A failed step writes repair.md with the step, the map entry and the window's elements, and the agent fixes the map or the tape from it.

No computer use needed

desktape is not an AI controlling your computer. It does not use Claude's (or any model's) computer use, and Claude Desktop's "Enable computer use" switch can stay off. A replay clicks through Windows UI Automation, step by step as the tape says. A model is involved only while an agent writes or repairs a tape, and even then it acts through desktape's look and act, which read the screen as text first.

A tape

name: add-marketplace-dialog
map: claude-desktop-win
steps:
  - focus: "@window"
  - click: "@sidebar.customize"
  - click: "@customize.plugins_tab"
  - caption: "Add a plugin marketplace"
  - click: "@plugins.add_plugin"
  - click: "@plugins.add_marketplace"
  - click: "@marketplace.from_repository"
  - click: "@marketplace.url"
  - type: "https://github.com/example/plugins.git"
  - expect: "@marketplace.use_url"
  - click: "@marketplace.cancel"

Steps address elements by role and label, wait for them and check them. Facts about an app (a tab that is a TabItem, a label that carries a description) go into a per-app map, so the tape can say @plugins.add_plugin.

The same file runs as a fast test, or in video mode with pauses, captions and redaction boxes burned in, plus an .srt.

desktape.py run tape.yaml
desktape.py run tape.yaml --mode video

Every run: 0 model calls. The method and the raw numbers are in the spike notes.

Safe by default

  • A default-deny allowlist of driver tools; nothing else reaches the desktop.
  • Every call goes to audit.jsonl, with typed secrets redacted.
  • The driver's telemetry, update check and script runner are switched off.
  • Recordings and OCR text are removed from the target after a run; a redacting tape keeps no unredacted copy.

Get started

git clone https://github.com/tatargabor/desktape && cd desktape
pip install -r requirements.txt
python3 desktape.py --selftest                       # offline, no host needed
export DESKTAPE_HOST=user@windows-host
python3 desktape.py look --map claude-desktop-win    # what is on screen, cheaply
python3 desktape.py run tapes/claude-desktop-add-marketplace-dialog.yaml

The target needs OpenSSH Server, Cua Driver in the user's session, and ffmpeg for video: Windows setup.
